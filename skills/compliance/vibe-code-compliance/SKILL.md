# Compliance and accessibility

Enforce legal compliance, consent flows, and accessibility standards before any user-facing product ships.

## Steps

1. Check if the product collects data, sells anything, targets the EU, or has public forms.
2. Read the matching checklist.
3. Flag missing legal pages, consent gaps, and accessibility failures to the user.
4. Apply accessibility fixes inline during UI generation.

## Checklists

| Surface | Read | When |
|---------|------|------|
| Policies, consent, data rights, ethical, AI disclosure | [legal.md](legal.md) | Launch prep, forms collecting data, signups, e-commerce, AI-generated deliverables |
| WCAG, keyboard nav, screen readers, overlays | [accessibility.md](accessibility.md) | Any UI with text, images, forms, or interactive elements |
